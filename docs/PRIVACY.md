# GeoStamp Privacy Notes

- Photos are selected explicitly through the file picker or drag-and-drop.
- This version processes photos in the browser and does not upload photo bytes to a GeoStamp server.
- Temporary object URLs and in-memory state are used for previews; there is no cloud photo storage.
- Browser geolocation is requested only after the user clicks Capture Location and grants permission.
- No map or external geocoding provider is integrated.
- Ad slots are placeholders; no advertising SDK is loaded.

Future analytics, remote geocoding, cloud storage, accounts or live ads require updated disclosures and appropriate consent. Browser extensions, the hosting provider and the device/browser are outside the app's direct control.
