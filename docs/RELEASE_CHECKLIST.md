# Release Checklist

- [ ] Install dependencies from a clean clone with supported Node/npm.
- [ ] Type-check, lint, unit tests and production build pass.
- [ ] Verify real JPEG GPS write, edit and removal with an independent EXIF reader.
- [ ] Verify original source files are unchanged after every export workflow.
- [ ] Test stamped JPEG output and batch ZIP results.
- [ ] Test corrupt/unsupported/large files and geolocation permission failures.
- [ ] Test current Chrome/Edge/Firefox and mobile Chrome/Safari where available.
- [ ] Check keyboard navigation, contrast, labels, touch targets and reduced motion.
- [ ] Confirm ad placeholders never obscure editor controls; no live ad SDK is active.
- [ ] Confirm privacy wording matches the actual data flow.
- [ ] Test HTTPS deployment and geolocation behavior.
- [ ] Verify PWA install behavior on target browsers; document offline limitations.
- [ ] Add an explicit license before presenting the repository as open source.
- [ ] Review supported-format claims, known limitations and rollback procedure.
